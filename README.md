# CLAW

CLAW is the private development repository for Animation Lab. The project is being reorganized around clean, testable modules while keeping a single Lua bundle that is easy to run.

## Boundaries

- `animation_lab_v6.lua` is the current working Animation Lab entry point.
- `src/` contains the new modular runtime and the Lycoris-inspired combat feature surface.
- `dist/AnimationLab.lua` is generated by the build and is the only runtime bundle a loader should fetch.
- Project Rain, the separate loot script, webhook secrets, and the Lycoris reference clone are intentionally excluded from this repository.
- Lycoris is used as behavioral research. CLAW does not blindly copy its invasive hooks, logging, or potentially restricted source.

## Build

Install a current Node.js release, then run:

```powershell
npm run build
npm run check
```

The builder has no third-party dependencies. It packages each module listed in `claw.manifest.json`, followed by the current Animation Lab entry point, into `dist/AnimationLab.lua`.

## Loader

`loader.lua` expects a secret-free distribution URL in `getgenv().CLAW_DIST_URL`. A private GitHub raw URL cannot be used anonymously, and a GitHub token must never be embedded in Lua. The source repository can remain private while the built artifact is published later through a separate read-only endpoint.

## Combat implementation map

The Combat work is organized into these independent layers:

1. state and settings
2. target selection and filtering
3. animation, sound, part, and effect detection
4. timing profiles and per-move overrides
5. defensive actions and scheduling
6. prediction, validation, fallback, and probability rules
7. attack and combat assistance
8. UI bindings, diagnostics, and lifecycle cleanup
